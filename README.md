# PlayPos

Касса и таймеры для детских игровых площадок. План разработки — в [PLAN.md](PLAN.md).

## Демо-версия (`demo/`)

Статический сайт без сборки:

- `demo/index.html` — лендинг продукта;
- `demo/brand.html` — бренд-бук: 3 палитры и варианты названия;
- `demo/app.html` — кликабельное демо программы: площадка с таймерами, продление с доплатой, счета (наличные/карта), смены, расходы, отчёты, тарифы с шаблонами, сотрудники с правами доступа, настройки.

Языки: русский и узбекский (латиница) — переключатель RU / UZ в меню, на экране входа и на сайте.

Вход в демо: Азиз (владелец) — PIN `1111`, Алия (кассир) — `2222`, Дилноза (администратор) — `4444`.

Данные демо хранятся только в браузере (localStorage) — это показ интерфейса, а не рабочая программа. В рабочей версии источник истины — сервер и PostgreSQL, права проверяются на сервере.

Локальный запуск: открыть `demo/index.html` в браузере или `npx serve demo`.
