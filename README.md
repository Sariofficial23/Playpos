# PlayPos

Касса и таймеры для детских игровых площадок. План разработки — в [PLAN.md](PLAN.md).

## Рабочая версия (касса для клиента)

- `demo/pos.html` (адрес `/pos`) — касса. Данные хранятся на сервере в PostgreSQL, права и деньги проверяются на сервере, несколько касс видят одно и то же (обновление каждые 5 секунд).
- `demo/setup.html` (адрес `/setup`) — первая установка: площадка + владелец.
- `api/rpc.js` + `lib/` — серверная часть (функция Vercel). Схема базы создаётся автоматически при первом запросе.

### Установка на Vercel (один раз)

1. Vercel → проект **playpos** → **Storage** → **Create Database** → **Neon (Postgres)** → подключить к проекту. Переменная `DATABASE_URL` добавится сама.
2. Vercel → **Settings → Environment Variables** → добавить `SETUP_TOKEN` (длинный секретный код, например 20 случайных символов).
3. **Deployments → Redeploy** (или любой `git push`), чтобы переменные подхватились.
4. Открыть `https://<сайт>/setup`, ввести код установки, название площадки, логин и пароль владельца.
5. Войти на `/pos` владельцем → «Тарифы» (проверить цены) → «Сотрудники» (создать кассиров с логином и PIN) → «Настройки» (принтер).

На кассовом компьютере открыть `https://<сайт>/pos` в Chrome, кассир входит своим логином и PIN.

### Локальный запуск и тесты

```
npm install
DATABASE_URL=postgres://... SETUP_TOKEN=любой-код npm run dev     # http://localhost:3000
TEST_DATABASE_URL=postgres://.../test_db npm test                  # база очищается!
```

## Админ-панель PlayPos (`/admin`) — клиенты и подписки

Только для владельца PlayPos, работает на Vercel (нужна база Neon и `SETUP_TOKEN`, см. выше).

1. Открыть `https://<сайт>/admin`. Первый раз — «Создание администратора»: код `SETUP_TOKEN`, ваша почта и пароль.
2. «＋ Новый клиент»: площадка, контакт, телефон, логин и пароль для активации, срок 1/3/6/12 месяцев или «Бессрочно», сумма. После создания показываются данные для отправки клиенту.
3. Клиент ставит программу для Windows и при первом запуске вводит этот логин и пароль (нужен интернет). Программа привязывается к его компьютеру.
4. «Продлить» — +1/+3/+6/+12 месяцев (от более поздней даты: текущего окончания или сегодня), история оплат в карточке клиента. В карточке — смена пароля, «Отвязать компьютер» (клиент сменил ноутбук), «Отключить доступ».

**Клиент забыл пароль владельца:** карточка клиента → «Сбросить пароль владельца» → одноразовый код из 8 цифр (24 часа, 5 попыток, только для компьютера этого клиента). Клиент в программе на экране входа нажимает «Забыли пароль владельца?», вводит код и новый пароль (нужен интернет). PIN сотрудников меняет сам владелец в «Сотрудниках».

Лицензия подписана ключом Ed25519 (создаётся автоматически и хранится в базе), программа проверяет её без интернета и обновляет каждые 6 часов, когда интернет есть. За 7 дней до конца касса показывает предупреждение; после окончания нельзя открыть новое посещение, продление или смену, но можно завершить детей на площадке и смотреть отчёты. После продления всё включается при следующей проверке (или после перезапуска программы).

## Версия для Windows (`desktop/`) — касса, сервер и база на одном компьютере

Для площадки с одним кассовым компьютером: не нужен интернет, Vercel и облачная база.

- **Установка:** скачать `PlayPos-Setup-*.exe` из [Releases](../../releases) (собирается автоматически GitHub Actions, `.github/workflows/desktop.yml`) и запустить. Появится ярлык PlayPos; программа стартует вместе с Windows.
- **Первый запуск:** «Активация программы» (логин и пароль из админ-панели, нужен интернет), затем «Установка площадки» — название, имя, логин и пароль владельца (код установки не нужен; установка возможна только на самом компьютере).
- **Обновления через интернет:** каждый `git push` собирает новую версию `1.3.N` и публикует её в Releases вместе с `latest.yml`. Установленная программа при наличии интернета проверяет обновления через 30 секунд после запуска и каждые 4 часа (меню «Касса» → «Проверить обновления» — вручную), скачивает их в фоне и показывает в кассе «Обновить сейчас». Перед установкой — резервная копия и остановка базы; данные и дети на площадке сохраняются. Если не нажать кнопку — обновление установится при закрытии программы. Версии до 1.3 обновлений не умеют: их один раз переустановить вручную.
- **Данные:** `%APPDATA%\PlayPos\data` (встроенная PostgreSQL — PGlite). Тот же серверный код, что и на сайте.
- **Резервные копии:** каждый день и при выходе — в `Документы\PlayPos\backups` (хранятся последние 30). Меню «Данные» → «Сделать резервную копию сейчас». Рекомендуем синхронизировать эту папку с Google Drive / флешкой.
- **Печать:** чек печатается сразу, без окна, на выбранный принтер (Zadig не нужен). Если тихая печать не удалась — откроется обычное окно печати.
- **Настройки → Принтеры:** все принтеры Windows с состоянием 🟢 Онлайн / 🔴 Офлайн / 🟠 Ошибка (нет бумаги, открыта крышка, замятие), обновляется каждые 10 секунд. Выбор принтера для чеков, «Тестовый чек» у каждого принтера, кнопка «Настройки принтеров Windows» (добавить принтер / драйвер). В меню кассы — значок «🖨 Принтер онлайн/офлайн»; если принтер офлайн, при оплате кассир видит предупреждение и может напечатать чек позже из «Счетов».

### Принтер Xprinter XP-T80Q (USB) — настройка

1. Подключить принтер USB-кабелем, включить. Установить драйвер Xprinter для Windows (с диска из комплекта или с сайта продавца/Xprinter). Порт — `USB001` (или другой `USB00x`).
2. Windows → «Принтеры и сканеры» → XP-T80Q → «Настройки печати»: бумага **80 мм** (в драйвере может называться «80(72.1) x …»), поля 0. Если в драйвере есть «Отрезка бумаги» / «Paper cut» — поставить «после документа». «Денежный ящик» — по желанию.
3. PlayPos → «Настройки» → «Принтеры» → «Обновить»: XP-T80Q должен быть 🟢 «Онлайн». Отметить его для чеков → «Тестовый чек».
4. Тестовый чек должен выйти ровно по ширине, с русскими и узбекскими буквами и без длинной пустой ленты: программа сама задаёт драйверу длину страницы по содержимому чека. Через драйвер Windows кодовая страница не нужна — текст печатается как в Windows.
5. Способ печати в «Настройках» — «Windows (драйвер)». Режим «USB напрямую» (Zadig) для XP-T80Q не нужен.

Если принтер показывает 🔴 «Офлайн»: проверьте кабель и питание; Windows замечает отключение USB-принтера с задержкой до минуты.

Разработка: `cd desktop && npm install && npm start` (Electron), сборка установщика: `npm run dist:win` (на Windows).

## Демо-версия (`demo/`)

Статический сайт без сборки:

- `demo/index.html` — рекламный сайт: возможности, скриншоты, кнопка «Скачать для Windows» (последний `PlayPos-Setup.exe` из Releases), телефон для связи и форма заявки. Заявки (имя, телефон) попадают в `/admin` → «Заявки» (нужна база Neon);
- `demo/brand.html` — бренд-бук: 3 палитры и варианты названия;
- `demo/app.html` — кликабельное демо программы: площадка с таймерами, продление с доплатой, счета (наличные/карта), смены, расходы, отчёты, тарифы с шаблонами, сотрудники с правами доступа, настройки.

Языки: русский и узбекский (латиница) — переключатель RU / UZ в меню, на экране входа и на сайте.

Вход в демо: Азиз (владелец) — PIN `1111`, Алия (кассир) — `2222`, Дилноза (администратор) — `4444`.

Данные демо хранятся только в браузере (localStorage) — это показ интерфейса, а не рабочая программа. В рабочей версии источник истины — сервер и PostgreSQL, права проверяются на сервере.

Локальный запуск: открыть `demo/index.html` в браузере или `npx serve demo`.

## Печать чека (термопринтер 58/80 мм)

После того как кассир подтверждает оплату, программа сразу отправляет чек на печать (выключается в «Настройках» → «Печатать чек после оплаты»). Повторно чек печатается из раздела «Счета» → «🖨 Чек». Ширина бумаги 58/80 мм выбирается в «Настройках».

Чтобы чек выходил **без окна печати**, на кассовом компьютере (Windows):

1. Установить драйвер принтера и в его настройках выбрать бумагу 80 мм (рулон), поля 0.
2. Сделать этот принтер **принтером по умолчанию** в Windows.
3. Запускать кассу ярлыком Chrome с флагом `--kiosk-printing`, например:
   `"C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk-printing --app=https://playpos-dusky.vercel.app/app`

### Способ 2: USB напрямую (как в Clopos) — рекомендуем

Браузер сам отправляет команды ESC/POS в принтер через WebUSB: без окна печати, с обрезкой ленты и открытием денежного ящика.

1. Подключить принтер по USB и запустить **Zadig** (zadig.akeo.ie): Options → List All Devices → выбрать принтер → драйвер **WinUSB** → Replace Driver.
   После этого обычная печать Windows на этот принтер работать не будет (печатает только касса).
2. Открыть кассу в **Chrome или Edge** по адресу https (сайт на Vercel подходит).
3. «Настройки» → «Способ печати» → «USB напрямую» → «Подключить принтер» → выбрать принтер → «Тестовый чек».
4. Кириллица печатается в кодировке CP866 (`ESC t 17`). Если вместо русских букв «кракозябры» — поменять номер кодовой страницы в настройках (у некоторых моделей 46 или 59). Узбекская латиница печатается на любой странице.
5. По желанию: «Открывать денежный ящик при оплате наличными».

Если USB-принтер недоступен, программа предупреждает кассира и печатает через Windows.
