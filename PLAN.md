# PlayPos — план разработки

Программа для детских игровых площадок: таймеры посещений, продления, счета (наличные / карта — только ручной учёт), смены, сотрудники с правами, тарифы, расходы, отчёты, печать талона. Продаётся многим площадкам по подписке (1 или 3 месяца, ключ активации).

Основа — 11 этапов из `PlayTime_Prompts.pdf` (версия требований 20.10.2026). Рабочее название PlayTime заменено на **PlayPos**. Ниже — этапы с дополнениями заказчика.

## Решения по бренду

- Название: **PlayPos** (альтернативы: PlayTime, TikTak Play, O'yinchoq — разбор в `demo/brand.html`).
- Палитра по умолчанию: вариант 3 **«Джунгли»** — бирюзовый `#0FB5A5`, фиолетовый `#6C5CE7`, жёлтый `#FFC83D`, тёмно-синий `#15324A`. Ещё два варианта: «Солнечная площадка», «Конфетти».
- Статусы таймера всегда одинаковые: зелёный / жёлтый / красный — не совпадают с цветом бренда.
- Шрифт: Nunito.

## Дополнения заказчика (к PDF)

1. **Кнопка «Продлить» на карточке**, особенно заметная, когда время заканчивается (жёлтая/красная карточка) + всплывающее уведомление с кнопкой «Продлить». Продление на N минут сразу добавляет сумму: в открытый счёт или новым счётом на доплату, если прошлый оплачен.
2. **Раздел «Сотрудники» с гибкими правами.** Владелец создаёт кассира/администратора и в карточке сотрудника включает/выключает каждое право отдельно: продажа, продление, приём оплаты, завершение, печать, своя смена, отчёты, расходы, возвраты, тарифы, сотрудники, настройки. Роль задаёт шаблон прав, который можно изменить. Выключатель блокировки входа. Права проверяются **на сервере** для каждой операции.
3. **Раздел «Тарифы» в меню.** Владелец площадки сам создаёт тарифы (10, 20, 30 минут, час, безлимит…), указывает, где тариф используется (вход / продление / оба), видит цену за минуту. Готовые шаблоны наборов тарифов по рынку, чтобы не настраивать с нуля. Использованные тарифы архивируются, а не удаляются.

## Что нужно от владельца перед этапом 1

- Аккаунт и провайдер PostgreSQL (Neon / Supabase / другой) — подключение через переменные окружения Vercel, секреты в чат не присылать.
- Домен (например, `playpos.uz`).
- Цены подписки на 1 и 3 месяца (на лендинге сейчас прочерки).
- Языки интерфейса: только русский в первой версии или сразу + узбекский.

## Как это делают другие системы (рынок)

- **Parafait, PlayOps, ROLLER, Aluvii** (зарубежные): таймер на ребёнка, вход через турникет или браслет/QR, оплата при входе за пакет времени и **автоматическая доплата за просрочку** при выходе (поминутно или блоками). Способ оплаты фиксируется на кассе при выходе.
- **Клубные системы СНГ (SmartShell, СмартТаймер)**: смены кассиров, отчёт по смене (X/Z-отчёт), журнал действий персонала, права по ролям.
- **CRM для детских центров (Битрикс24 и др.)**: абонементы, карточки семей, напоминания о продлении — для разовых посещений площадки избыточно.

Что берём в PlayPos: выход через панель «Закрыть счёт» со способом оплаты; отчёт «Касса по кассирам» (наличные / карта / возвраты); сверка кассы по сменам; список всех оплат. Варианты на потом: абонементы на N посещений, онлайн-бронь праздников.
